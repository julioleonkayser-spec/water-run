# Water Run

A small browser game I made for the charity: water project. You carry water home. Grab the yellow jugs and jump over the rocks before the time runs out.

**Goal:** collect 12 jugs in 30 seconds.

## How to play

1. Press **Start**.
2. Click the game area, tap it, or press **Space** (or the up arrow) to jump.
3. Touch a jug: +1 point. Touch a rock: -1 point.
4. Get 12 or more points before the timer hits 0 to win.
5. Press **Reset** any time to start over.

## What it has

- A person who walks and jumps, drawn with CSS
- Score that changes right away (green when you get a jug, red when you hit a rock)
- A water bar that fills up as you collect jugs
- A floating +1 or -1 when you hit something
- A start screen and an end screen
- 30 second timer
- A message that tells you what just happened
- Random win and lose messages at the end
- Works on a phone and on a computer

## Level ups

- **Obstacle:** rocks take away 1 point
- **Reset button:** puts the score, timer and screen back to the start
- **Confetti:** falls when you win

## Files

- `index.html` - the page
- `styles.css` - the colors and layout (charity: water yellow and blue)
- `script.js` - the game

## Put it online with GitHub Pages

1. Make a new repo on GitHub and upload these files.
2. Go to Settings > Pages.
3. Under Branch pick `main` and `/ (root)`, then Save.
4. Wait a minute. The link will be `https://YOUR-USERNAME.github.io/REPO-NAME/`
